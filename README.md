# PSA connectors and terminals

Collaborative illustrated catalogue of PSA automotive connectors and terminals, with manufacturer part numbers, cross-references, wire sizes and application details.

## Browse the catalogue

**[Open the catalogue on GitHub Pages](https://ludwig-v.github.io/psa-connector-catalogue/)**

Read and search the catalogue directly on GitHub Pages. No installation or local web server is needed. The site includes enlarged photographs, associated-terminal links, distributor searches and a print layout.

## Contribute

- [Suggest a correction](https://github.com/ludwig-v/psa-connector-catalogue/issues/new?template=correction.yml).
- [Propose a new part](https://github.com/ludwig-v/psa-connector-catalogue/issues/new?template=new-part.yml).
- Edit an entry through GitHub and submit a pull request; see [CONTRIBUTING.md](CONTRIBUTING.md).

Include the relevant part number and supporting documentation or photographs. Each catalogue entry also has a **Suggest a correction** link. Contributions are reviewed before publication.

Third-party logos and photographs retain their original rights.
